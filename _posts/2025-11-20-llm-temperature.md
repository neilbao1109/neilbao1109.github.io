# LLM 中 Temperature 参数详解

## 一、直观理解

Temperature（温度）控制的是模型输出的**随机性/创造性**程度：

| Temperature | 效果 | 适用场景 |
|:-----------:|:----:|:--------:|
| 低 (0~0.3) | 确定性强、保守、可预测 | 代码生成、事实问答、数学计算 |
| 中 (0.5~0.8) | 平衡创造性与连贯性 | 一般对话、文章写作 |
| 高 (0.8~1.5+) | 随机性强、多样、富有创意 | 创意写作、头脑风暴、诗歌 |

---

## 二、原理详解

### 1. 模型输出的本质

LLM 在每一步生成下一个 token 时，会对词表中所有 token 计算一个原始分数（**logits**），记为 $z_i$。

### 2. 标准 Softmax（无 Temperature）

$$P(x_i) = \frac{e^{z_i}}{\sum_{j} e^{z_j}}$$

### 3. 加入 Temperature 的 Softmax

$$P(x_i) = \frac{e^{z_i / T}}{\sum_{j} e^{z_j / T}}$$

其中 **$T$** 就是 Temperature 参数。

---

### 4. 关键：Temperature 如何改变概率分布

#### 🔹 当 T → 0（极低温度）
$$z_i / T \to \pm\infty$$

- logits 之间的差异被**无限放大**
- 概率分布趋近于 **one-hot**（概率最高的 token → 1，其余 → 0）
- 效果：**贪心解码（Greedy Decoding）**，每次都选最可能的 token

#### 🔹 当 T = 1（默认温度）
$$P(x_i) = \frac{e^{z_i}}{\sum_{j} e^{z_j}}$$

- 就是标准 Softmax，使用模型原始学到的概率分布

#### 🔹 当 T → ∞（极高温度）
$$z_i / T \to 0$$

- 所有 logits 被压缩为接近 0
- 概率分布趋近于**均匀分布**
- 效果：几乎是**随机选词**，输出混乱无意义

## 三、具体示例

假设模型对下一个 token 输出 logits 为：

| Token | "猫" | "狗" | "桌子" | "量子" |
|:-----:|:----:|:----:|:------:|:------:|
| logit | 5.0 | 4.0 | 1.0 | 0.5 |

不同 Temperature 下的概率分布：

```
T = 0.2 (低温):
  猫:   0.993   ██████████████████████████████
  狗:   0.007   ▏
  桌子: ≈0    
  量子: ≈0    

T = 1.0 (标准):
  猫:   0.588   █████████████████
  狗:   0.216   ██████
  桌子: 0.011   ▏
  量子: 0.006   ▏

T = 2.0 (高温):
  猫:   0.371   ███████████
  狗:   0.272   ████████
  桌子: 0.103   ███
  量子: 0.078   ██
```

可以清晰看到：
- **低温**：概率集中在最优选项，几乎必然选"猫"
- **高温**：概率被"摊平"，"桌子""量子"这些低概率词也有机会被选中

## 四、物理学类比（名称由来）

Temperature 这个名字来源于**统计力学中的玻尔兹曼分布**：

$$P(E_i) = \frac{e^{-E_i / kT}}{Z}$$

- **低温**：粒子倾向于待在低能态（有序、确定）
- **高温**：粒子在各能态间均匀分布（混乱、随机）

LLM 中的 Softmax with Temperature 与此**数学形式完全同构**。

---

## 五、与其他采样参数的关系

```
原始 logits
    │
    ▼
┌─────────────┐
│ Temperature  │  ← 缩放 logits，改变整体分布形状
└─────┬───────┘
      ▼
┌─────────────┐
│   Top-K      │  ← 只保留概率最高的 K 个 token
└─────┬───────┘
      ▼
┌─────────────┐
│   Top-P      │  ← 只保留累积概率达到 P 的最小 token 集合
│  (nucleus)   │
└─────┬───────┘
      ▼
  采样输出 token
```

**Temperature 是最底层的控制**，它在 Top-K / Top-P 之前改变概率分布的"形状"。

## 六、代码演示

```python
import numpy as np

def softmax_with_temperature(logits, temperature):
    scaled = np.array(logits) / temperature
    exp_scaled = np.exp(scaled - np.max(scaled))  # 数值稳定
    return exp_scaled / exp_scaled.sum()

logits = [5.0, 4.0, 1.0, 0.5]
tokens = ["猫", "狗", "桌子", "量子"]

for T in [0.2, 0.5, 1.0, 2.0]:
    probs = softmax_with_temperature(logits, T)
    print(f"T={T}: {dict(zip(tokens, [f'{p:.4f}' for p in probs]))}")
```

输出：
```
T=0.2: {'猫': '0.9933', '狗': '0.0067', '桌子': '0.0000', '量子': '0.0000'}
T=0.5: {'猫': '0.8756', '狗': '0.1185', '桌子': '0.0004', '量子': '0.0001'}
T=1.0: {'猫': '0.5876', '狗': '0.2163', '桌子': '0.0108', '量子': '0.0065'}
T=2.0: {'猫': '0.3713', '狗': '0.2725', '桌子': '0.1033', '量子': '0.0785'}
```

## 七、总结

> **Temperature 本质上是对 logits 做除法缩放后再 Softmax，通过控制概率分布的"尖锐程度"来调节输出的确定性与随机性。低温使分布尖锐（确定性高），高温使分布平坦（随机性高）。**
