# 非对称加密的数学原理详解

## 一、核心思想：单向陷门函数

非对称加密的根基是**单向陷门函数（Trapdoor One-way Function）**：

```
正向计算：已知 x → 容易求 f(x)
逆向计算：已知 f(x) → 极难求 x（没有陷门信息时）
有陷门时：已知 f(x) + 陷门信息 → 容易求 x
```

> **类比**：把一本书撕碎很容易，但从碎片还原极难——除非你有另一本一模一样的书（陷门）。

## 二、RSA 算法（最经典）

### 1. 数学基础

#### （1）欧拉定理

若 $\gcd(a, n) = 1$，则：

$$a^{\varphi(n)} \equiv 1 \pmod{n}$$

其中 $\varphi(n)$ 是**欧拉函数**，表示小于 $n$ 且与 $n$ 互质的正整数个数。

#### （2）欧拉函数的性质

- 若 $p$ 是素数：$\varphi(p) = p - 1$
- 若 $p, q$ 是不同素数：$\varphi(pq) = (p-1)(q-1)$

#### （3）模逆元

若 $ed \equiv 1 \pmod{\varphi(n)}$，则 $d$ 是 $e$ 关于 $\varphi(n)$ 的模逆元。

### 2. 密钥生成过程

```
步骤1：选择两个大素数 p, q（各自通常 1024 bit 以上）
步骤2：计算 n = p × q
步骤3：计算 φ(n) = (p-1)(q-1)
步骤4：选择公钥指数 e，满足 1 < e < φ(n) 且 gcd(e, φ(n)) = 1
        （常用 e = 65537 = 2¹⁶ + 1）
步骤5：计算私钥指数 d，满足 e × d ≡ 1 (mod φ(n))
        （用扩展欧几里得算法求解）
```

```
公钥 = (n, e)    → 公开
私钥 = (n, d)    → 保密
p, q, φ(n)       → 销毁
```

### 3. 加密与解密

```
加密（任何人都可以做）：
    密文 C = M^e mod n        （M 是明文，M < n）

解密（只有私钥持有者）：
    明文 M = C^d mod n
```

### 4. 正确性证明 ⭐

**要证明**：$(M^e)^d \equiv M \pmod{n}$

即证明：$M^{ed} \equiv M \pmod{n}$

**证明过程**：

因为 $ed \equiv 1 \pmod{\varphi(n)}$，所以存在整数 $k$ 使得：

$$ed = 1 + k \cdot \varphi(n)$$

因此：

$$M^{ed} = M^{1 + k\varphi(n)} = M \cdot (M^{\varphi(n)})^k$$

**情况一**：$\gcd(M, n) = 1$

由欧拉定理：$M^{\varphi(n)} \equiv 1 \pmod{n}$

$$M^{ed} = M \cdot 1^k = M \pmod{n}  \quad \checkmark$$

**情况二**：$\gcd(M, n) \neq 1$（即 $M$ 是 $p$ 或 $q$ 的倍数）

不妨设 $p | M$（即 $M \equiv 0 \pmod{p}$），但 $\gcd(M, q) = 1$（因为 $M < n = pq$）。

由费马小定理对 $q$：

$$M^{q-1} \equiv 1 \pmod{q}$$

$$M^{ed} = M^{1+k(p-1)(q-1)} = M \cdot (M^{q-1})^{k(p-1)} \equiv M \cdot 1 \equiv M \pmod{q}$$

同时 $M \equiv 0 \pmod{p}$，所以 $M^{ed} \equiv 0 \equiv M \pmod{p}$

由**中国剩余定理**（因为 $\gcd(p,q) = 1$）：

$$M^{ed} \equiv M \pmod{n}  \quad \checkmark$$

### 5. 安全性依据：大整数分解困难

```
已知：n（公开的）
求解：p 和 q

这就是大整数分解问题（Integer Factorization Problem）
```

| n 的位数 | 分解难度 |
|---------|---------|
| 256 bit | 普通电脑可破 |
| 512 bit | 专业团队可破 |
| 1024 bit | 目前勉强安全 |
| 2048 bit | 当前安全标准 |
| 4096 bit | 高安全需求 |

> 如果攻击者能分解 $n = p \times q$，就能算出 $\varphi(n)$，进而算出 $d$，密码体系即被破解。

### 6. 数值例子

```
步骤1：p = 61, q = 53
步骤2：n = 61 × 53 = 3233
步骤3：φ(n) = 60 × 52 = 3120
步骤4：选 e = 17（gcd(17, 3120) = 1 ✓）
步骤5：求 d，使得 17d ≡ 1 (mod 3120)
        d = 2753（因为 17 × 2753 = 46801 = 15 × 3120 + 1）

公钥：(3233, 17)
私钥：(3233, 2753)

加密 M = 65：
    C = 65^17 mod 3233 = 2790

解密 C = 2790：
    M = 2790^2753 mod 3233 = 65 ✓
```

## 三、椭圆曲线密码学（ECC）

### 1. 椭圆曲线方程

在有限域 $\mathbb{F}_p$（$p$ 为大素数）上的椭圆曲线：

$$y^2 \equiv x^3 + ax + b \pmod{p}$$

条件：$4a^3 + 27b^2 \not\equiv 0 \pmod{p}$（确保曲线无奇异点）

### 2. 椭圆曲线上的点运算

曲线上的点构成一个**阿贝尔群**，核心是**点加法**：

#### （1）点加法：$P + Q = R$

给定 $P = (x_1, y_1)$，$Q = (x_2, y_2)$，$P \neq Q$：

$$\lambda = \frac{y_2 - y_1}{x_2 - x_1} \pmod{p}$$

$$x_3 = \lambda^2 - x_1 - x_2 \pmod{p}$$

$$y_3 = \lambda(x_1 - x_3) - y_1 \pmod{p}$$

$$R = (x_3, y_3)$$

> 注意：这里的"除法"是**模逆运算**。

#### （2）点倍乘：$P + P = 2P$

$$\lambda = \frac{3x_1^2 + a}{2y_1} \pmod{p}$$

其余公式相同。

#### （3）标量乘法

$$kP = \underbrace{P + P + \cdots + P}_{k \text{ 次}}$$

实际使用**双倍-加法（Double-and-Add）**算法高效计算。

### 3. 椭圆曲线离散对数问题（ECDLP）

```
已知：基点 G 和点 Q = kG（均为曲线上的点）
求解：标量 k

这就是 ECDLP —— 目前没有经典多项式时间算法
```

```
正向：已知 k 和 G → 求 Q = kG        → 容易（O(log k) 次点运算）
逆向：已知 Q 和 G → 求 k             → 极难（目前最优亚指数算法）
```

### 4. ECDH 密钥交换

```
Alice                              Bob
选私钥 a（随机大整数）              选私钥 b（随机大整数）
计算 A = aG                        计算 B = bG
         ──── 交换 A, B ────
计算 S = aB = a(bG)               计算 S = bA = b(aG)

共享密钥：S = abG（相同！）

窃听者知道 G, A=aG, B=bG，但无法求出 abG
（这是椭圆曲线 Diffie-Hellman 问题）
```

### 5. ECDSA 数字签名（简化版）

```
参数：曲线 E, 基点 G, 阶 n
私钥：d（随机整数）
公钥：Q = dG

签名（对消息哈希 z）：
    1. 选随机数 k，计算 (x₁, y₁) = kG
    2. r = x₁ mod n
    3. s = k⁻¹(z + rd) mod n
    4. 签名为 (r, s)

验证：
    1. u₁ = zs⁻¹ mod n
    2. u₂ = rs⁻¹ mod n
    3. 计算点 (x₁, y₁) = u₁G + u₂Q
    4. 验证 r ≡ x₁ (mod n)
```

**正确性**：

$$u_1G + u_2Q = zs^{-1}G + rs^{-1}(dG) = s^{-1}(z + rd)G = kG \quad \checkmark$$

### 6. ECC vs RSA 安全等级对比

| 安全强度 (bit) | RSA 密钥长度 | ECC 密钥长度 | 比值 |
|:---:|:---:|:---:|:---:|
| 80 | 1024 | 160 | 6:1 |
| 112 | 2048 | 224 | 9:1 |
| 128 | 3072 | 256 | 12:1 |
| 192 | 7680 | 384 | 20:1 |
| 256 | 15360 | 521 | 30:1 |

> ECC 用更短的密钥达到同等安全性，这在移动设备、IoT 中极具优势。

## 四、Diffie-Hellman 密钥交换（基于离散对数）

### 1. 数学基础：离散对数问题

在素数 $p$ 的乘法群 $\mathbb{Z}_p^*$ 中：

```
已知：g（生成元）, p（大素数）, y = g^x mod p
求解：x

这就是离散对数问题（DLP）
```

### 2. 协议流程

```
公开参数：大素数 p, 生成元 g

Alice                              Bob
选私钥 a                            选私钥 b
计算 A = g^a mod p                  计算 B = g^b mod p

         ──── 交换 A, B ────

计算 S = B^a mod p                  计算 S = A^b mod p
       = g^(ba) mod p                     = g^(ab) mod p

共享密钥 S = g^(ab) mod p
```

### 3. 安全性

窃听者知道 $g, p, A = g^a, B = g^b$，要计算 $g^{ab}$。

这是**计算性 Diffie-Hellman 问题（CDH）**，被认为与离散对数问题同等困难。

## 五、ElGamal 加密（基于离散对数）

### 密钥生成
```
选大素数 p，生成元 g
私钥：x（随机）
公钥：y = g^x mod p
```

### 加密
```
选随机数 k
c₁ = g^k mod p
c₂ = M · y^k mod p
密文 = (c₁, c₂)
```

### 解密
```
M = c₂ · (c₁^x)⁻¹ mod p
```

### 正确性
$$c_2 \cdot (c_1^x)^{-1} = M \cdot y^k \cdot (g^{kx})^{-1} = M \cdot g^{xk} \cdot g^{-xk} = M \quad \checkmark$$

### 统一的安全范式

所有非对称加密都遵循同一模式：

$$\boxed{\text{公钥} = f(\text{私钥})}$$

其中 $f$ 是单向陷门函数：
- **RSA**：$n = p \times q$（分解困难）
- **DH/ElGamal**：$y = g^x \bmod p$（离散对数困难）
- **ECC**：$Q = kG$（椭圆曲线离散对数困难）

> **量子威胁**：Shor 算法可以在量子计算机上多项式时间内解决大整数分解和离散对数问题，因此 RSA、DH、ECC 在量子时代都将不安全。这推动了**后量子密码学**（基于格、编码、哈希等新困难问题）的发展。
