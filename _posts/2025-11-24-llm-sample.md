# 归一化 + 采样 详解

## 一、为什么需要归一化？

经过 Top-K / Top-P 过滤后，部分 token 被移除，剩余 token 的概率**加起来不再等于 1**。

```
过滤前（概率和 = 1.0）：
  猫: 0.40
  狗: 0.25
  鸟: 0.15
  桌子: 0.05
  量子: 0.03
  其他: 0.12
  ─────────
  总和: 1.00 ✅

Top-K=3 过滤后（概率和 ≠ 1.0）：
  猫: 0.40
  狗: 0.25
  鸟: 0.15
  ─────────
  总和: 0.80 ❌  ← 不是合法概率分布！
```

**概率分布的基本要求：所有概率之和必须等于 1。** 否则无法进行合法的随机采样。

### 归一化操作

$$P'(x_i) = \frac{P(x_i)}{\sum_{j \in \text{nucleus}} P(x_j)}$$

```
归一化：每个概率 ÷ 总和(0.80)

  猫: 0.40 / 0.80 = 0.500
  狗: 0.25 / 0.80 = 0.3125
  鸟: 0.15 / 0.80 = 0.1875
  ──────────────────────
  总和: 1.00 ✅  ← 合法概率分布！
```

**本质：等比例放大剩余 token 的概率，填补被移除 token 留下的"空间"。**

## 二、什么是"采样"？

### 最容易混淆的关键点

> **采样 ≠ 选最大值。采样是按概率随机抽取。**

### 具体理解

想象一个**转盘**：

```
┌─────────────────────────────────────────┐
│                                         │
│          ┌───────────────┐              │
│         ╱    猫 50.0%     ╲             │
│        ╱                   ╲            │
│       │                     │           │
│       │                     │           │
│        ╲    狗 31.25%      ╱            │
│         ╲                 ╱             │
│          ╲  鸟 18.75%   ╱               │
│           └─────────────┘               │
│                 ▲                       │
│                 │ 指针                   │
│                                         │
└─────────────────────────────────────────┘

转一次转盘：
  - 50.0%  的概率停在 "猫"
  - 31.25% 的概率停在 "狗"
  - 18.75% 的概率停在 "鸟"
```

每次生成一个 token 就是**转一次转盘**。

## 三、采样的具体算法

### 方法：逆变换采样（Inverse Transform Sampling）

这是计算机中最常用的按概率采样方法：

```
步骤：
1. 生成一个 [0, 1) 之间的均匀随机数 r
2. 计算累积概率
3. 找到 r 落在哪个区间 → 对应的 token 就是结果
```

### 逐步示例

```
候选 token 及归一化概率：
  猫:  0.500
  狗:  0.3125
  鸟:  0.1875

构建累积概率分布（CDF）：
  ┌──────────┬────────┬────────────┬──────────┐
  │  区间     │ 0~0.5  │ 0.5~0.8125 │ 0.8125~1 │
  │  Token    │  猫    │    狗       │   鸟     │
  └──────────┴────────┴────────────┴──────────┘
  0          0.5     0.8125          1.0

数轴表示：
  0                    0.5              0.8125           1.0
  ├────── 猫 ──────────┼───── 狗 ────────┼──── 鸟 ────────┤
```

**模拟多次采样：**

```
第1次: r = 0.23 → 落在 [0, 0.5)     → 选 "猫" ✅
第2次: r = 0.71 → 落在 [0.5, 0.8125) → 选 "狗" ✅
第3次: r = 0.95 → 落在 [0.8125, 1.0) → 选 "鸟" ✅
第4次: r = 0.12 → 落在 [0, 0.5)      → 选 "猫" ✅
第5次: r = 0.49 → 落在 [0, 0.5)      → 选 "猫" ✅
第6次: r = 0.55 → 落在 [0.5, 0.8125) → 选 "狗" ✅
第7次: r = 0.88 → 落在 [0.8125, 1.0) → 选 "鸟" ✅
```

**采样 10000 次的统计结果会趋近于：猫≈50%，狗≈31.25%，鸟≈18.75%**

## 四、代码实现

### 从零实现

```python
import numpy as np

def sample_from_distribution(tokens, probs):
    """完整的归一化 + 采样过程"""
  
    # ========== 第1步：归一化 ==========
    prob_sum = sum(probs)
    normalized_probs = [p / prob_sum for p in probs]
  
    print(f"归一化前: {dict(zip(tokens, [f'{p:.4f}' for p in probs]))}")
    print(f"概率总和: {prob_sum}")
    print(f"归一化后: {dict(zip(tokens, [f'{p:.4f}' for p in normalized_probs]))}")
  
    # ========== 第2步：计算累积概率 ==========
    cumulative = []
    running_sum = 0
    for p in normalized_probs:
        running_sum += p
        cumulative.append(running_sum)
  
    print(f"累积概率: {[f'{c:.4f}' for c in cumulative]}")
  
    # ========== 第3步：生成随机数并查找区间 ==========
    r = np.random.random()  # [0, 1) 均匀随机数
  
    chosen_index = 0
    for i, cum_prob in enumerate(cumulative):
        if r < cum_prob:
            chosen_index = i
            break
  
    print(f"随机数 r = {r:.4f} → 选中 '{tokens[chosen_index]}'")
    return tokens[chosen_index]


# 示例：Top-K=3 过滤后的结果
tokens = ["猫", "狗", "鸟"]
probs = [0.40, 0.25, 0.15]  # 和为 0.80，不是 1

print("=" * 50)
result = sample_from_distribution(tokens, probs)
```

输出示例：
```
==================================================
归一化前: {'猫': '0.4000', '狗': '0.2500', '鸟': '0.1500'}
概率总和: 0.8
归一化后: {'猫': '0.5000', '狗': '0.3125', '鸟': '0.1875'}
累积概率: ['0.5000', '0.8125', '1.0000']
随机数 r = 0.6234 → 选中 '狗'
```

### PyTorch（LLM 框架中的真实写法）

```python
import torch

def generate_next_token(logits, temperature=1.0, top_k=50, top_p=0.9):
    # 1. Temperature 缩放
    logits = logits / temperature
  
    # 2. Top-K 过滤
    if top_k > 0:
        top_k_values, _ = torch.topk(logits, top_k)
        min_top_k = top_k_values[:, -1].unsqueeze(-1)
        logits = torch.where(logits < min_top_k, 
                            torch.full_like(logits, float('-inf')), 
                            logits)
  
    # 3. Softmax → 概率（自动归一化，-inf → 0）
    probs = torch.softmax(logits, dim=-1)
  
    # 4. Top-P 过滤
    if top_p < 1.0:
        sorted_probs, sorted_indices = torch.sort(probs, descending=True)
        cumulative_probs = torch.cumsum(sorted_probs, dim=-1)
      
        # 移除累积概率超过 p 的 token
        mask = cumulative_probs - sorted_probs > top_p
        sorted_probs[mask] = 0
      
        # 重新归一化 ← 就是这一步！
        sorted_probs = sorted_probs / sorted_probs.sum(dim=-1, keepdim=True)
      
        # 还原原始顺序
        probs = torch.zeros_like(probs)
        probs.scatter_(dim=-1, index=sorted_indices, src=sorted_probs)
  
    # 5. 采样 ← 就是这一步！
    next_token = torch.multinomial(probs, num_samples=1)
  
    return next_token
```

## 五、采样 vs 贪心 vs Beam Search

```
┌─────────────────────────────────────────────────────────┐
│                   解码策略对比                            │
├──────────────┬──────────────────────────────────────────┤
│              │                                          │
│  贪心解码     │  永远选概率最大的 token                    │
│  (Greedy)    │  argmax(probs)                           │
│              │  → 确定性输出，每次结果相同                 │
│              │  → 可能陷入重复                            │
│              │                                          │
├──────────────┼──────────────────────────────────────────┤
│              │                                          │
│  随机采样     │  按概率随机抽取                            │
│  (Sampling)  │  multinomial(probs)                      │
│              │  → 每次结果可能不同                        │
│              │  → 配合 T/K/P 控制多样性                   │
│              │                                          │
├──────────────┼──────────────────────────────────────────┤
│              │                                          │
│  Beam Search │  同时维护 B 条最优路径                     │
│              │  → 全局更优但计算量大                      │
│              │  → 常用于翻译等任务                        │
│              │                                          │
└──────────────┴──────────────────────────────────────────┘
```

### 直观对比

```
概率分布: 猫(0.5)  狗(0.3125)  鸟(0.1875)

贪心:   猫 → 猫 → 猫 → 猫 → 猫    (永远选最大)
采样:   猫 → 狗 → 猫 → 鸟 → 猫    (按概率随机，有变化)
```

## 七、总结

```
归一化：让截断后的概率重新满足"和为1"的基本要求
        数学操作 → 每个概率除以总和
      
采样：  按概率随机选一个 token（不是选最大的！）
        核心算法 → 生成随机数，查找其落入的累积概率区间
      
为什么不直接选最大？
  → 选最大（贪心）会导致输出单调、重复
  → 按概率采样才能产生多样、自然的文本
  → Temperature/Top-K/Top-P 控制"多样"的程度
```
